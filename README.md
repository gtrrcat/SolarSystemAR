# 🪐 Solar System AR — Приложение дополненной реальности (Unity + Vuforia)

Интерактивный AR-проект «Планеты Солнечной системы», разработанный на движке **Unity** с использованием технологии компьютерного зрения **Vuforia Engine**.

## Реализованный функционал:
* **AR-трекинг**: Распознавание 4 карт (Земля, Марс, Юпитер, Венера) через Vuforia Target Manager.
* **3D-модели планет**: Отображение 3D-сфер планет с наложением детальных текстур.
* **Анимация вращения**: C#-скрипт (`RotatePlanet.cs`) для непрерывного плавного вращения планет вокруг своей оси.
* **Информационные карточки**: World Space UI-панели с подробным описанием каждой планеты (диаметр, спутники, факты), появляющиеся в 3D-пространстве рядом с моделью.
* **Оптимизация трекинга**: Настроено сглаживание позиционирования (`Smooth Transition`) для стабильного отображения объектов при движении камеры.

## 🛠 Технологический стек:
* **Unity 6** (Built-in Render Pipeline)
* **Vuforia Engine 10+**
* **Язык программирования**: C#
* **UI**: Unity UI / TextMeshPro (World Space Canvas)

## Как запустить и протестировать:
1. Клонируйте репозиторий и откройте проект в **Unity 6** (или Unity 2022+).
2. Убедитесь, что в `Window -> Vuforia Configuration` подключен валидный App License Key.
3. Откройте главную сцену (SampleScene) из папки `Assets/Scenes/`.
4. Нажмите **Play (▶)** в Unity и наведите веб-камеру на изображение любой из карточек планет.
5. Карточки планет лежат в Assets/Cards
